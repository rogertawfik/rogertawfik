Outstanding Research Award, 2026 NSF REU Cohort

I work on a quality control system for clinical gait video that runs on the recording device and tells the clinician on the spot whether a clip is usable, before downstream analysis. One QC specification, implemented three times (a Python reference pipeline, native Android in Kotlin, native iOS in Swift) and validated across all three platforms on a shared 120-video study corpus, with the focus and lighting gates set from instrumented-walkway ground truth rather than chosen by inspection.
